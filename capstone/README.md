# CS 499 Capstone Materials

TrakCode is the artifact for all three CS 499 enhancement categories. This
folder holds the code as it was before and after each enhancement, plus the
written narratives. The rest of this repository is the finished, enhanced
TrakCode; see the [main README](../README.md) to run it.

**Code review video:** [youtu.be/w6H_jH92UV8](https://youtu.be/w6H_jH92UV8)

| Folder | What it is |
|---|---|
| [`original/`](original/) | TrakCode before any enhancements, as reviewed in the code review video |
| [`enhancement-1-software-design/`](enhancement-1-software-design/) | Milestone Two: software design and engineering |
| [`enhancement-2-algorithms/`](enhancement-2-algorithms/) | Milestone Three: algorithms and data structures (only the files this milestone changed) |
| [`enhancement-3-databases/`](enhancement-3-databases/) | Milestone Four: databases |
| [`narratives/`](narratives/) | The enhancement narratives and the professional self-assessment |

Each enhancement folder is the code as submitted for that milestone. Later
work continued on the same codebase, so the repository root is the most
current version.
